# Тексты для автоматизации и контроля

Замените квадратные скобки фактическими данными. Не выдавайте плановый сценарий за найденный дефект или работающее правило.

## Роли маршрута

```text
Исполнитель: [имя] — готовит материал задачи Г.
Проверяющий: [имя] — сопоставляет результат с P1–P5.
Координатор: [имя] — следит за передачей и контрольной точкой.
Руководитель: [имя или роль] — решает вопрос срока, приоритета и блокера.
Заказчик: [имя или роль] — принимает результат после проверки.
```

## Маршрут задачи Г

```text
Готово к работе → В работе → На внутренней проверке → Доработка → Готово к согласованию → Принято.

Готово к работе → В работе: есть бриф, R3, P3 и данные из задачи В.
В работе → На внутренней проверке: исполнитель передал результат и способ проверки.
На внутренней проверке → Доработка: проверяющий сохранил замечание.
Доработка → Готово к согласованию: исполнитель сохранил ответ о доработке.
Готово к согласованию → Принято: принимающая роль сохранила решение.
```

```text
Получатель: [роль и причина].

Ручной маршрут при недоступности: [действие и место записи].
```

## Правило передачи на проверку

```text

Получатель: проверяющий, потому что он сопоставляет результат с P1–P5.
Решение человека: достаточно ли материалов для проверки P3.
```

```text

Получатель: исполнитель и координатор.

```

## Контрольная точка

```text
Сигнал: [задача не передана на проверку / замечание без ответа / приближение срока].
Получатель: координатор и [исполнитель / проверяющий / руководитель].
Что проверяем: [материал, следующее действие или причина задержки].
```


## Трассировка

```text
R3: новый неоплаченный резерв действует 20 минут.
P3: проверка состояния товара до окончания резерва и после его окончания.
В: «Подготовить данные для проверки резервирования» — [ссылка].
Бриф: «Бриф проверки резервирования — подготовка данных» — [ссылка].
Г: «Выполнить сквозную проверку резервирования» — [ссылка].
Замечание или решение: [ссылка].

Проверенный путь: R3 → P3 → В → бриф → Г → замечание или решение.
```
