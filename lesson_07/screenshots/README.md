# Снимки автоматизации и контроля

Загрузите сюда свои PNG. Имена файлов и содержание кадров указаны в [задании](../README.md#что-сдать). Снимайте существующие записи проекта и доступные настройки. Если функция закрыта, сохраните настоящий экран ограничения и опишите ручной маршрут. Не добавляйте личные телефоны, почту, секреты и личную переписку.
